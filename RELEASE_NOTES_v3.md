# AeroBooster — Release v3.0.0 (17 November 2026)

Open defensive publication. Documents under CC BY 4.0, code under MIT. All performance figures are
simulation outputs, not measurements, pending the P1 bench tests (T1–T6).

## What's new since v2
- **Corrected P1-B build pack** — manufacturing specification and a 9-sheet drawing set for one shared
  bench platform built in two interchangeable fills: **P1-S** (nitrate solar salt) and **P1-X** (scrap cast
  iron + ordinary sand). Four design corrections from the first P1 pack are locked in.
- **P1-X simplified build + first-heat moisture vent** — a no-machining version using available scrap and
  ordinary sand (iron where heat must travel, sand everywhere else), and a top-centre vent that releases
  steam on the first heat-up.
- **Open component sourcing catalogue** — 16 components with specifications and live international/regional
  supplier links, for anyone who wants to build and measure the prototype.
- **Performance improvements over prior art (cited)** — insulation, dry-store high-temperature operation,
  contact-conductance, and an optional second charging input. Quantified with a transient model.
- **Simulation code** — PV-direct matching, storage-media comparison, and a storage-time / peak-temperature
  experiment.

## Acknowledgement of prior art
AeroBooster does **not** originate electric/PV-charged thermal-storage cooking; that field is established.
This work builds on and cites it — among others: NTNU (O. J. Nydal) and Morpho Solar (Norway) with
A. H. Tesfay (Ethiopia); PV + sand thermal storage from Ghana; high-density rock storage from Uganda; and
Ethiopian electric *mitad* research. See `AeroBooster_Improvements_over_PriorArt.pdf` for the full citation
list. AeroBooster's contribution is the specific engineering integration and the improvements documented
here.
