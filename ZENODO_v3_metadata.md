**Description (paste):**
AeroBooster is an open, patent-free design for a photovoltaic-charged high-temperature thermal store that
cooks and heats from stored heat, for communities with limited electricity or fuel. This version adds a
corrected P1-B bench build pack (manufacturing specification and a 9-sheet drawing set) for one shared
platform in two interchangeable fills — nitrate solar salt (P1-S) and scrap cast iron with ordinary sand
(P1-X) — a simplified no-machining P1-X build with a first-heat moisture vent, an open component sourcing
catalogue, a set of performance improvements documented against the prior art with citations, and the
simulation code behind the figures. All performance figures are model outputs pending bench measurement.

This work does not originate electric/PV-charged thermal-storage cooking; it builds on and cites existing
work (NTNU / Morpho Solar, Norway, with A. H. Tesfay, Ethiopia; PV + sand storage, Ghana; high-density rock
storage, Uganda; Ethiopian electric mitad research). The contribution is the specific engineering
integration and the documented improvements. An irrevocable humanitarian-use pledge applies, unchanged
since version 1.
